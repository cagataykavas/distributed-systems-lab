# Distributed Systems Lab

Interview-oriented implementations of reliability and consistency patterns used in production systems.

## Topics

- idempotency
- retries with exponential backoff and jitter
- circuit breaker
- leader-election concepts
- distributed locks
- event sourcing
- saga orchestration/choreography
- transactional outbox
- caching and invalidation
- consistency trade-offs / CAP intuition

The goal is not to pretend a few scripts replace production infrastructure. Each lab isolates one idea so its failure modes are easy to inspect.
